# SkillSync – Student Skill Exchange Platform

## 📌 About the Project

SkillSync is a Student Skill Exchange Platform designed to encourage collaborative learning and peer-to-peer knowledge sharing among students. It provides a platform where students can share their skills, discover skills offered by other students, and connect with peers to learn and improve their abilities.

The project focuses on database management, organizing student information, managing skill listings, and maintaining relationships between students and skill-exchange activities.

## 🎯 Objectives

- Encourage peer-to-peer learning and knowledge sharing.
- Enable students to showcase the skills they can teach.
- Help students discover skills they want to learn.
- Manage student and skill-exchange information efficiently.
- Apply DBMS concepts to a practical, real-world application.

## ✨ Key Features

- Student information management.
- Skill listing and categorization.
- Management of skills offered and skills wanted.
- Skill-exchange request management.
- Organized storage and retrieval of project data.
